# 관심 기술

## 다뤄본 기술
- **Java** — 온보딩 과정에서 주력으로 사용하는 언어입니다.
- **Spring** — 간단한 CRUD API를 만들어보며 컨트롤러와 서비스 계층 분리를 경험했습니다.
- **Database** — 테이블을 직접 설계하고 SQL로 조회·수정하는 작업을 해봤습니다.
- **Test Code** — JUnit으로 단위 테스트를 작성하며 코드를 검증하는 흐름을 익혔습니다.
- **Git / GitHub** — 브랜치를 나누고 PR로 병합하는 워크플로우를 연습하고 있습니다.
